# Agenda Ya

## Descripción

Agenda Ya es una plataforma web para agendamiento de citas en línea.

## Objetivo

Facilitar a los usuarios la consulta de servicios, horarios disponibles y el agendamiento de citas.

## Funciones principales

- Registro de usuarios
- Inicio de sesión
- Consulta de servicios
- Consulta de horarios
- Agendamiento de citas
- Gestión de citas
- Administración de servicios y horarios

## Roles

### Usuario
Puede consultar servicios, horarios disponibles y agendar citas.

### Administrador
Puede gestionar usuarios, servicios, horarios y citas.
